# Security Reporting

Clipper is a local developer alpha. Keep it bound to loopback and use only authorized, trusted media. It is not a hostile-media sandbox or a hosted multi-user service.

Do not report exploit details, credentials, private videos or raw logs in public issues. When the GitHub repository is created, enable private vulnerability reporting and use its Security tab to contact the maintainer. Until a private contact is configured, do not disclose sensitive reproduction material publicly.

The source-only GitHub package has no downloaded tools/models or developer job data. Integrity manifests do not provide publisher authentication. Dependency and media-parser vulnerabilities still require review. No security certification, thermal guarantee or publishing permission is implied.
